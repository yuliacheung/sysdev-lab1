# 实例3：引号的区别

- 单引号 '...'：所有字符都是字面量，不做任何替换（变量、转义都不生效）
- 双引号 "...": 变量替换($var)、命令替换$(...)、反斜杠转义仍生效，其余是字面量
- ANSI引号 $'...': 专门处理转义序列，如 \n \t 会变成真正的控制字符

测试（name=Yuga）：
- echo '单引号看$name和感叹号!' → 单引号看$name和感叹号!  （$name未替换）
- echo "双引号看$name和感叹号!" → 双引号看Yuga和感叹号!  （$name被替换）
- echo $'ANSI引号换行\n看效果' → 换行符真正生效，输出分两行

题目要求：输出同时包含字面量$、!和换行符的字符串
命令：echo $'字面量美元符号$ 感叹号! 换行符\n结束'
输出：
字面量美元符号$ 感叹号! 换行符
结束
